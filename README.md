# Sugarless Shenanigans — GitHub Pages

A single-page, animated chocolate brand presentation.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and the `assets` folder (keep the folder structure).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

The 3D chocolate bar uses Three.js from a CDN, so visitors need an internet connection.
The site also loads Google Fonts.

## Edit
- Change page copy in `index.html`.
- Replace `assets/sugarless-shenanigans-logo.png` to use another logo image.
- The chocolate model is generated in Three.js in the module script near the bottom of `index.html`.

## Product-content note
The ingredient details follow the supplied two-page ingredient document. It describes A2 milk and hazelnut praline, so the concept is **not vegan or nut-free**. The document says free from refined white sugar, not sugar-free. Final nutrition values, vitamin/mineral quantities, allergen declarations and claims require verification before real-world sale.
